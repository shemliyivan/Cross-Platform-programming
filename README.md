# CrossApp
Наскрізний проєкт з крос-платформного програмування.
Предметна область: Бібліотека. Сутності: Book, BookCopy, Reader, Loan.
Призначення: облік видач примірників книг читачам.
## Запуск
dotnet build
dotnet run --project src/Cli

## Інваріанти доменної моделі

**Сутність BookCopy (Примірник):**
* `Id` та `Isbn` не можуть бути порожніми (`ArgumentException`).
* `Issue()`: неможливо видати примірник, який уже має статус `IsIssued = true` (`InvalidOperationException`).
* `Return()`: неможливо повернути примірник, який не був виданий.

**Сутність Loan (Видача):**
* Стан `Status` контролюється через перелічування (`Active` -> `Closed`). Неможливо закрити вже закриту видачу (`InvalidOperationException`).
* `Close(returnedOn)`: дата повернення не може бути раніше дати видачі (`ArgumentOutOfRangeException`).

**Міждоменні правила (наприклад, ліміт у 5 книг на читача):**
Такі правила вимагають доступу до історії всіх видач конкретного читача (бази даних). 
Щоб сутності залишалися "чистими" та незалежними від інфраструктури (Репозиторіїв), перевірка подібних правил делегується Доменним Сервісам (наприклад, `LendingService`). 
Сервіс рахує кількість відкритих видач у базі, і лише після успішної перевірки викликає метод зміни стану в сутності.
